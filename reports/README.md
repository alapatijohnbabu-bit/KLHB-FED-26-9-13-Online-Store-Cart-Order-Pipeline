# Reports and Phase Deliverables

Keep phase reports, the final report, presentations and evaluation evidence here.

Follow the course submission norms:
- Make phase status and implementation claims match the current source code.
- Keep the report, README, requirements and diagrams consistent.
- Include each member's real contribution and commit evidence.
- Tag phase deliverables such as `review-1`, `review-2` and `final`.
- Do not describe planned features or expected results as implemented or tested.
- State clearly if payment is simulated or if data is only sample/in-memory data.
